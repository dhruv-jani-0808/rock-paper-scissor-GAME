# Rock Paper Scissor Game 🎮

A simple browser-based **Rock Paper Scissor** game built with HTML, CSS, and JavaScript. The user plays against the computer. The computer’s choice is made randomly, and the winner is decided based on classic rules.

Live Demo: [rock-paper-scissor-game (Netlify)](https://rock-paper-scissor-game-jd.netlify.app/)

## Features

- Play Rock, Paper, or Scissor vs the computer  
- Randomized computer choice using `Math.random()`  
- Immediate feedback: win, lose, or draw  
- Responsive UI with images (rock, paper, scissor)  
- Clean and minimal design  

---

## How It Works

1. **User Selection**: The user clicks on one of the three options.  
2. **Computer Choice**: The JS logic picks one of the three randomly.  
3. **Decision Logic**: Using `if-else` or `switch`, the code determines the winner.  
4. **Display Result**: The result (win / lose / draw) is shown on the screen.
